# DOOOOM?

A RuneLite plugin with independent spawn and death sounds for Doom of Mokhaiotl. Each sound has its own enable setting and volume slider.

## Run locally

On Windows, run `.\gradlew.bat run` from the project directory. This starts RuneLite in developer mode with the plugin loaded. Follow the [Using Jagex Accounts](https://github.com/runelite/runelite/wiki/Using-Jagex-Accounts) instructions to sign in to the development client.

## Install through RuneLite

The development launch only installs the plugin in your local development client. To make it available through RuneLite's Plugin Hub, submit it to the [RuneLite Plugin Hub](https://github.com/runelite/plugin-hub) and wait for review and acceptance. Once it is published, find **DOOOOM?** in the RuneLite Plugin Hub panel and install it there.
